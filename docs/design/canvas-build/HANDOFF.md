## How to rebuild and publish a page
1. Read the live index first: Artifact `read` with `path: project/canvas.json`. Save it as `artifact-files/project/canvas.json` (the scripts read it) and copy it to `design/project/canvas.json`.
2. Run the page script (for example `python -I mk_settings.py`). It rewrites the page's frames and adds them to `design/project/canvas.json`.
3. Publish with the Artifact tool: `file_path` = `design/project/canvas.json`, `files` = the changed frames, `root` = the `design` folder.
4. If the publish is refused, someone edited the canvas. Re-read the index (step 1), run the script again, publish again. Never resend an old copy.
5. Do not run a script that rewrites `canvas.json` and then publish it without step 1. It would undo hand edits (moved frames, renamed notes).

## Rules that bit before
- Frames are 1440 x 900. Long pages use a scrolled frame (a `translateY` offset), not a tall frame.
- No em-dashes. Hyphens only.
- Section titles sit on the left of each section, size 200, like the Customers title.
- Percent signs inside `%`-formatted Python strings must be `%%`.
